# 本葬受付台帳 v0.12（試作）

## 起動
GitHub Pages など HTTPS 配信できる場所へ、このフォルダの中身をそのまま置いてください。Safari で開いて「ホーム画面に追加」するとアプリ風に使えます。

Excel読み書きには SheetJS を使用します。初回起動時だけライブラリ取得のためインターネット接続が必要です。Service Worker が取得後にキャッシュするため、その後はオフライン利用を想定しています。

## 主な機能
- 第1宗務所 182寺院の内蔵名簿
- ひらがな / カタカナ / 漢字で寺号検索
- 名簿人物候補（住職・東堂・副住職・徒弟・御山内・寺族1/2）
- 本葬配役候補
- 収入 / 支出の即時切替
- 金額クイック加算 + 手入力
- 預かり子ID
- IndexedDB 自動退避
- 検索・修正・削除
- 表一覧
- 追加名簿 JSON バックアップ / 復元
- Excel 読込時の列チェック
- 保存時に _MMDD_HHMM.xlsx を付けた新規保存

## Excel列
アプリから保存した Excel を次回そのまま読み込む設計です。

## v0.2 修正
- iPad/Safariで寺号検索中、1文字入力するたびにキーボードが閉じる問題を修正。
- 寺号検索は入力欄を再描画せず、候補一覧だけを更新する方式へ変更。
- 検索・修正画面と表一覧の検索欄も同様に、連続入力中にキーボードが閉じない方式へ変更。

## v0.3 修正
- 「＋ 預かりを追加」で何も起きないことがある問題を修正。
- 親レコードの登録成功を確認してから、子ID（例: P001-01）を採番して預かり入力フォームへ遷移するよう変更。
- 預かり入力画面では子ID・預かり区分・持参者を明示。
- Service Worker のキャッシュ世代を更新し、古い app.js が残りにくいよう修正。

## v0.5 更新点

- Service Worker の `skipWaiting()` / `clients.claim()` により新版へ早く切り替えるよう変更
- GitHub Pages 上のアプリ本体を Network First に変更（オンライン時は最新版を優先、オフライン時はキャッシュ）
- Service Worker 登録時に `updateViaCache: 'none'` と `update()` を使用
- 新しい Service Worker が有効になったとき、一度だけ自動再読み込み
- 画面上部に `v0.5` を表示
- 旧 `temple-reception-*` キャッシュを有効化時に削除

※ IndexedDB の作業データ・追加名簿は、アプリ本体のキャッシュとは別領域です。通常のバージョン更新では削除しません。


## v0.5 変更点
- 登録済みの本人レコードを検索・表一覧から開いた場合でも「＋ 預かりを追加」を表示。
- 編集中の親レコードを更新してから、既存の子IDを確認し、次の枝番（例: P001-02）で預かり入力を開始。
- 預かりレコード自身には追加ボタンを表示しない。


## v0.6 変更点
- 表一覧に「通常表示 / 全列表示」の切替を追加。
- 全列表示ではExcel出力対象の全列を横スクロールで確認可能。
- 全列表示の先頭2列（No. / レコードID）を横スクロール時に固定。
- 表一覧または検索結果から個別フォームを開いた場合、「← 表一覧へ戻る」「← 検索結果へ戻る」を表示。
- 更新・削除後も、元の表一覧または検索結果へ戻るよう変更。
- 表一覧の検索条件・教区・受付区分・通常/全列表示を保持。
- 表一覧からフォームを開いて戻った際、縦横スクロール位置を復元。
- 検索結果からフォームを開いて戻った際、ページ位置を復元。


## v0.8 変更点
- 配役候補の末尾に「未案内」を追加。
- 表一覧に「案内区分」フィルターを追加（すべて / 案内寺院 / 未案内随喜寺院）。
- 未案内随喜寺院は `配役 = 未案内` で判定。
- 案内寺院は配役が入力済みで、かつ「未案内」ではないレコードとして判定。
- 配役空欄は案内・未案内のどちらにも自動分類しない。


## v0.9 変更点
- 「検索・修正」と「表一覧」の検索でも、寺号のひらがな / カタカナ検索に対応。
- 各レコードの寺籍番号から第1宗務所名簿のフリガナを参照し、寺号漢字とフリガナの両方を検索対象に追加。
- ひらがな / カタカナは新規入力時と同じ正規化処理を使用するため、キーボード切替なしで検索可能。
- 漢字検索、氏名、役職、配役、ID等の従来検索はそのまま維持。


## v0.10 変更点
- 寺号検索を部分一致から前方一致へ変更。「りゅう」で検索した場合、「リュウ…」で始まる寺院だけを候補にし、「コウリュウジ」のように途中に「リュウ」を含む寺院は除外。
- 「検索・修正」「表一覧」の文字検索も、各検索対象フィールドの前方一致に統一。ひらがな / カタカナ正規化は維持。
- 「＋ 預かりを追加」で子レコード入力へ切り替えた直後、必ずフォーム最上部へスクロールするよう修正。
- 登録済み本人を検索・表一覧から開いた編集フォームでは、画面上部に「＋ 預かりを追加」を表示。
- 新規本人の入力中は従来どおり画面下部に「＋ 預かりを追加」を表示し、登録済み編集時は上部ボタンを使う構成に整理。


## v0.12 変更点
- 全列表示の列幅をiPad向けに列ごと最適化。固定寺号列を約3文字分まで縮小。
- 金額列・ID・氏名・配役・備考などを用途別の幅に調整。
- 預かり入力時、親に寺号がある場合は「○○寺を使う」候補を表示し、教区・寺籍番号・寺号をワンタップで引き継げる。
- Excel書き出し時の列幅も同様に見直し。
